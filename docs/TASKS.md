# Cherrypicker 실사용 작업

## 상태 규칙

- `[ ]`: 일반 대기
- `[-]`: 현재 진행 중
- `[>]`: 사용자가 승인한 단 하나의 다음 작업
- `[~]`: 보류. 다시 활성화하기 전에는 진행하지 않음
- `[x]`: 완료 조건을 모두 검증한 작업

작업을 시작할 때 `[>]`를 `[-]`로 바꾸고, 완료 조건을 모두 관찰·실행한 뒤에만 `[x]`로 바꾼다. 후속 작업을 확정했을 때만 하나의 `[>]`를 새로 지정한다.

## 현재 기준선

로그인 없는 로컬 workspace, 공용 카탈로그, 조합 추천, 결제 기록, 선택적 계정 동기화, 카드·프로모션 수집·검수·revision·rollback 기반은 이미 구현되어 있다. 아래 목록은 이 기반을 재구축하는 작업이 아니라 비공개 실사용까지 남은 사용자 흐름을 완성하는 순서다.

  - 기본 포함·카드별 할인 제외·명시된 거래 종류 제외·다른 카드에 정책이 전파되지 않는 경계를 회귀 테스트로 확인했다. 대표 추천 snapshot은 원래의 실적 우선 순위로 돌아왔고, 전체 68개 파일·551개 테스트, lint, production build와 diff 형식 검사가 통과했다. 로컬 `/api/health`는 정상이고 공개 catalog는 게시 카드 14장·실적 정책 0장이다. 이번에도 연결된 브라우저가 없어 데스크톱·모바일 실제 UI 검증은 미완료다. 두산 후보·게시 카드 데이터·운영 DB·배포는 변경하지 않았다.
